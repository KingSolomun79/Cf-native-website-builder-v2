## 4. Findings

- **F1 (Medium, verified, RESOLVED in the QA remediation commit).** `createRevisionBuild` does not check the proof gate: with the gate shut, a Revision Request on a pre-existing ORIGINAL_DESIGN build starts a new OD Build, violating "ORIGINAL_DESIGN cannot start unless the gate is open". Requires a pre-existing OD build (gate was open at least once), so not a cold-start bypass. Fix shape: gate check in `createRevisionBuild` when the parent's Site Generation is ORIGINAL_DESIGN; tripwire QA-F1 flips automatically.
- **F2 (Medium, verified, RESOLVED in the QA remediation commit).** `readScreenshotBytes` accepts arbitrary bytes (extension-based MIME only); garbage is frozen as the canonical Reference Screenshot and flows into evidence/vision. The retained infra (`reference-input.validateScreenshot` with PNG magic/size checks) exists but is unwired. Fix shape: validate before freezing; add `REFERENCE_SCREENSHOT_INVALID` code; tripwire QA-F2.
- **F3 (Medium, verified, RESOLVED in the QA remediation commit).** `FABRICATED_YEAR` only matches `since 19xx/20xx`; "Established 1998", "Founded in 2004", "Est. 1999" pass deterministic validation, weakening the factual-provenance rule ahead of QA-A. Fix shape: broaden the founding-year pattern (careful with false positives on addresses/phone numbers — restrict to word-boundary `est(ablished)?\.?/founded( in)? + year` forms); tripwire QA-F3.
- **F4 (Low, verified, deferred) — #12 JSON-LD parse-only.** `JSON.parse("null")`/`"123"` pass `INVALID_JSON_LD`. Semantic truthfulness remains covered by the QA-B `TRUTHFUL_JSON_LD` mandatory gate at release time, so impact is bounded; fix is a one-line object-shape check.
